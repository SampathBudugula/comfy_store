
# Comfy Store

A furniture e-commerce website built using React and Vite.

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Vite

## Project Overview
Comfy Store is an online furniture shopping application where users can browse products, view product details, and explore furniture collections.

## React + Vite
This project uses Vite for a fast development environment with Hot Module Replacement (HMR) and ESLint support.
